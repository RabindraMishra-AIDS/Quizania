# Quizania

AI-powered quiz app built with FastAPI.

What it is
- Quizania generates and serves quizzes using AI to help learners practice and test knowledge quickly.
- Backend built with FastAPI; frontend uses simple HTML/JavaScript.

Key features
- AI-generated quiz questions and answers
- REST API built with FastAPI
- Lightweight frontend for taking quizzes

Quick start
1. Install dependencies: `pip install -r requirements.txt`
2. Run the app (development): `uvicorn main:app --reload`
3. Open the frontend in your browser (see project files for the UI)
